# Virtual Office 2D Game

A 2D office simulation game built with Godot 4. Experience the daily life of an office worker!

## 🎮 Game Features

- **2D Top-Down View**: Navigate around the office
- **Player Movement**: Walk around with arrow keys or WASD
- **Interactive Office**: Desks, coffee machines, furniture
- **NPC System**: Meet and interact with colleagues
- **Task System**: Complete tasks to earn money and advance career
- **Energy & Morale**: Manage your character's well-being
- **Camera System**: Follows the player around the office

## 🎯 How to Play

### Controls
- **Movement**: Arrow Keys or WASD
- **Interact**: Spacebar (E)
- **Pause**: P

### Objectives
1. Complete daily tasks to earn money
2. Manage your energy and morale
3. Interact with NPCs
4. Build your career in the virtual office

## 🛠️ Setup Instructions

### Prerequisites
- Godot 4.x installed
- Basic knowledge of Godot engine

### Installation
1. Clone this repository
2. Open `project.godot` in Godot
3. Run the project (F5)

### Development
- Main scene: `scenes/main.tscn`
- Player script: `scripts/player.gd`
- Office manager: `scripts/office_manager.gd`
