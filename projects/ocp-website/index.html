deploy.ocp
# Deploy to staging with health check + rollback SET APP "my-api" SET PORT "3000" LOG "▸ Pushing to staging..." RUN git push staging main LOG "▸ Health check..." TRY FOR i 1 5 RUN curl -sf https://{APP}.staging:{PORT}/health SET RESULT "OK" END CATCH LOG "✗ Health failed. Rolling back..." RUN git revert HEAD --no-edit RUN git push staging main END LOG "✓ Deploy complete — {APP} is live!"
Features

Why OC+?

Built for devs who want automation that just works — no ceremony, no complexity.

7 Keywords, Infinite Power

Full language in 7 keywords: RUN, SET, LOG, IF, FOR, TRY, CATCH. Zero learning curve.

Docker Sandbox

Scripts run in isolated containers. Read-only FS, no network by default, no shell injection.

Built-in Retry & Recovery

TRY/CATCH blocks + FOR loops for retry logic. Handle failures gracefully.

Telegram Integration

Deliver script output directly to Telegram. Perfect for cron jobs and monitoring.

Cron-Native

Schedule scripts as cron jobs. System reports, git sync, Docker cleanup — automated.

Open Source

MIT licensed. The DSL interpreter is free. The cloud platform is optional.
