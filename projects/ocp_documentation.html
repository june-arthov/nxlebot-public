OC+ (Octane) DSL – Dokumentasi OpenClaw

1. Apa itu OC+?

OC+ (kadang disebut Octane) adalah bahasa domain‑specific (DSL) yang kami ciptakan untuk meng‑orchestrasi tugas‑tugas DevOps/automation secara bersih dan mudah dibaca. Bahasa ini dirancang khusus agar dapat dipanggil dari dalam OpenClaw melalui skill ocp-run.

2. Persiapan Lingkungan

  1. Pastikan python3 terinstall (sudah ada di WSL).
  2. Berikan hak eksekusi pada interpreter: 
    chmod +x /home/nxelleai/.openclaw/workspace/ocp_interpreter.py
  3. Pastikan folder skill sudah ada: 
    mkdir -p /home/nxelleai/.openclaw/skills/ocp-run
  4. Letakkan SKILL.md (sudah dibuat) di folder di atas.
Semua file berada di dalam workspace /home/nxelleai/.openclaw/workspace.

3. Format File Skrip OC+

Skrip OC+ harus berakhiran .ocp. Contoh sederhana (deploy.ocp) dapat dilihat di bawah.

# deploy.ocp
# Set variabel
set PROJECT = "myapp"
set ENV = "prod"

# Build step
run "npm install"
run "npm run build"

# Deploy step
run "scp -r ./dist user@server:/var/www/$PROJECT"
run "ssh user@server 'systemctl restart $PROJECT'"

Baris yang dimulai dengan # dianggap komentar.

4. Menjalankan Skrip lewat OpenClaw

  1. Pastikan skill ter‑register: 
    openclaw skills list | grep ocp-run
    Jika belum muncul, jalankan openclaw skills reload atau restart gateway.
  2. Jalankan skrip dengan perintah openclaw run ocp-run <path>. Contoh: 
    openclaw run ocp-run /home/nxelleai/.openclaw/workspace/deploy.ocp
  3. Output (stdout/stderr) akan ditampilkan pada sesi OpenClaw yang memanggil perintah.
Pastikan skrip tidak mengeksekusi perintah yang berbahaya tanpa otorisasi. Intervensi manual diperlukan untuk perintah yang mengubah file system kritis.

5. Mengintegrasikan ke Bot Baru

Jika Anda memiliki bot (misalnya mybot) yang ingin mengeksekusi OC+, cukup tambah perintah berikut ke file mybot.yaml atau ke AGENTS.md:

commands:
  - name: deploy
    description: Deploy aplikasi menggunakan OC+
    exec: openclaw run ocp-run /path/to/your/script.ocp

Setelah bot di‑restart, ketik /deploy di chat Telegram dan bot akan memanggil skill ocp-run secara otomatis.

6. Fitur yang Sudah Tersedia

  • set – Deklarasi variabel string.
  • run "cmd" – Eksekusi perintah shell dengan substitusi variabel $VAR.
  • echo "msg" – Tulis ke stdout.
  • cd – Ubah direktori kerja.

Fitur lanjutan parallel, try/catch, if/else, dan for belum diimplementasikan – dapat ditambahkan pada iterasi berikutnya.

7. Troubleshooting

  • Permission denied: Pastikan interpreter memiliki hak eksekusi (chmod +x).
  • Skill not found: Jalankan openclaw skills reload atau restart gateway (openclaw gateway restart).
  • Command fails inside script: Periksa output error di sesi OpenClaw; gunakan echo untuk debugging variabel.
